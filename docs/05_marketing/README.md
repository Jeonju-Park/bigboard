## 만들 것
- `bm_bigshot_radar.md` — 프리미엄형 BM + 단위경제 (Bear/Base/Bull 3시나리오 방식 권장)
- `gtm_bigshot_radar.md` — D-30~D+30 (3월 정치인 재산공개 시즌을 D0 후보로 검토 — 연중 최대 트래픽 이벤트)

## 채널 1차 가설 (Bullseye 외곽링)
1. ASO 롱테일: "내부자 매매", "임원 주식 매도", "공시 알림"
2. 커뮤니티 런칭: 디스콰이엇 + 주식 커뮤니티 (폭락장 타이밍 = 정서적 순풍)
3. 숏폼: "이 회사 임원들 지난달에 팔았습니다" 포맷 (사실 서술만 — 법적 가드레일)

## 법적 가드레일 (마케팅 카피에도 동일 적용)
투자 조언 워딩 금지. 모든 소재에 "투자 자문 아님" 고지.
