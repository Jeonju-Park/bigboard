## 2026-08-01 (시세 연결)
- **호출량 추정을 정정했다.** 시세 API 는 종목별이 아니라 **날짜별 전 종목**(2,872건)을 준다.
  1,000건씩 3회면 하루치가 끝나므로 1년치도 약 865회 — 한도 10,000 의 9%.
  앞서 "종목당 250회 x 690종목 = 172,500회로 불가능"이라 본 건 조회 축을 잘못 가정한 것이었다
- 52주·스파크라인은 **매번 1년치를 다시 계산**한다. 과거 시계열을 커밋하면 매일 수 MB 씩
  히스토리가 불어난다. 한도에 여유가 있으니 다시 받는 쪽이 낫다
- **거래정지 종목은 고가·저가·거래량이 0 으로 온다**(종가만 유지). 그 0 을 52주 계산에 넣어
  high52 가 0 이 되는 버그가 있었다 → 거래 없는 날은 종가를 고가·저가로 쓴다
- **스파크라인을 sparklines.json 으로 분리.** 종목당 122개 숫자라 합치면 gzip 155KB 인데
  필요한 화면은 종목·피드 상세뿐이다. stocks.json 211KB → 28KB
- 스파크라인은 **0 기준선을 쓰지 않는다**(주가는 0 에서 시작하지 않는다). min~max 스케일 +
  최저·최고 축 라벨 + "세로축은 기간 내 범위" 문구로 과장을 막는다
- `formatAmountShort` 에 **조 단위** 추가 — 없으면 시총이 "15,346,481억" 으로 나온다
- CI 는 UTC 0시대(KST 오전 9시대) 실행에서만 --history 를 돌린다. 나머지는 당일 시세만

## 2026-08-01 (전략 확정 — 유저 결정)
- **배포를 먼저, 로그인은 그 다음.** 배포는 지금 가능하고 로그인은 개인정보 처리방침·탈퇴 경로
  준비가 필요해 배포를 늦춘다. 원래 전략(선배포 → 4~6주 반응 검증)과도 일치하며,
  반응 데이터가 '무엇을 동기화할지'의 근거가 된다
- **로그인 백엔드 = Supabase.** Auth + Postgres 한 세트라 팔로우 데이터를 바로 테이블로 옮길 수 있고,
  정적 SPA 에서 클라이언트 SDK + RLS 로 서버 없이 동작한다. 나중 푸시 백엔드로도 쓴다(부록 A-3)
- ⚠️ **HashRouter ↔ OAuth 충돌 주의**: 인증 제공자가 토큰을 URL 해시로 돌려주면 우리 라우팅과
  충돌한다. Supabase 의 **PKCE 플로우**(`?code=` 로 받음)를 써서 피한다. 붙일 때 최우선 확인 항목
- ⚠️ 계정을 받는 순간 개인정보 처리방침·회원 탈퇴·데이터 삭제 경로가 필요하다. 실명 공시 서비스라
  더 엄격하게 본다

## 2026-08-01 (증권사 딥링크 — 오픈이슈 O2 해소)
- **조사 결과: 증권 3사 모두 커스텀 스킴을 공개 문서로 내지 않는다.** 추측한 스킴을 넣으면
  iOS 에서 "주소가 유효하지 않습니다" 오류창이 떠 앱이 고장난 것처럼 보인다 → 스킴을 쓰지 않는다
- 대신 **플랫폼별로 검증 가능한 수단만** 쓴다:
  · Android — Google Play 에서 확인한 패키지명으로 `intent:` 실행 + `S.browser_fallback_url`.
    스킴 추측이 필요 없고 앱이 없으면 크롬이 알아서 웹으로 보낸다
    (com.kiwoom.heromts / com.miraeasset.trade / com.samsungpop.android.mpop)
  · iOS — 증권사 웹 URL. 유니버설 링크가 등록돼 있으면 앱이 열리고 아니면 웹이 열린다. 오류창 없음
  · 데스크톱 — 웹 URL
- **주문 정보를 넘기지 않는다.** 종목 코드조차 싣지 않는다 — 특정 종목 주문 화면으로 바로 보내면
  '권유'로 읽힐 여지가 생긴다(규칙 1). 앱을 여는 데서 멈춘다
- 자동 실행(location.href 대입) 대신 **사용자가 직접 누르는 `<a href>`** — 브라우저가 제스처 없는
  앱 전환을 막는다 (출처: 토스페이먼츠 딥링크 문서)
- ⚠️ 실기기 미검증. 최악의 경우가 '웹페이지가 열림'(이전 동작)이라 회귀 위험은 없다.
  확인되면 broker.ts 의 verified 를 true 로 올릴 것

  totalAmount 가 app 에선 number, 실제로는 null 이 흔했다 (타입체커는 패키지 안만 본다)

- **정정 upsert 키 = (종목코드, 인물, 거래일, 계획여부)**. rcept_no 로는 원본-정정을 못 묶는다. 한계는 설계문서 §4에 기록
- **대표 거래일 = 공시일 이하 변동일 중 최근**. 한 보고서가 수개월치를 담는 일이 흔하고, 제출자 오타로 미래 날짜(2030년)가 섞인 실제 사례가 있었다. 원문은 details 에 그대로 보존
- **혼합 보고서(매수+매도 198건)는 금액·단가를 null 로** 둔다. 순증감 수량과 총 거래대금의 단위가 어긋나 "55,530주 = 1,774억"처럼 읽혔다
- **단가 0원·음수는 null 로 취급**. 무상취득을 0으로, 정정 상쇄쌍을 음수로 적은 원문이 있다. 0을 진짜 단가로 쓰면 총액이 거짓이 된다
- **랭킹은 단가가 확인된 공시만 집계**하고 그 기준을 화면에 병기한다 (원문이 아닌 파생값)

## 2026-07-31 (STEP 0 — 셋업)
- **스타일 방식 = CSS Modules + CSS 변수** (vanilla-extract 탈락). 클로드 디자인 프로젝트가 이미 순수 CSS 변수로 작성돼 있어 재작성·동기화 비용이 없고, Vite 내장이라 의존성 0. 토큰 강제는 `npm run check:tokens` 로 보완
- **tokens.ts 가 유일 소스, CSS 는 생성물**. `scripts/build-tokens.mjs` 가 tokens.ts → `tokens.generated.css` 를 만들고 predev/prebuild 에 연결. Node 24 네이티브 TS 실행이라 빌드 의존성 0개. CSS 를 직접 고치면 덮어써짐
- **폰트 = 하이브리드 조달**. Pretendard 는 jsdelivr 동적 서브셋 woff2, Paperlogy 800·IBM Plex Mono·Material Symbols 는 CDN. 4종 모두 실제 로드 확인
- **라우터 = `react-router` v8.3.0** (`react-router-dom` 아님). v2 문서는 react-router-dom 을 지정했으나 해당 패키지의 7.12.0~8.2.0 이 CSRF 권고(GHSA-qwww-vcr4-c8h2) 범위이고 7.x 최신(7.18.2)도 포함된다. 우리는 RSC·서버 액션을 안 쓰므로 실제 노출은 없지만, STEP 1 착수 전이라 전환 비용이 0이어서 옮김
- **tsconfig 3분할** (app/node/솔루션). 브라우저 코드에 Node 타입을 넣지 않아 `process.env` 사용이 타입 단계에서 막힌다 = 규칙 5의 구조적 방어
- 아이콘 규격(20/24px)을 `iconSize` 토큰으로 신설 — §6 이 정한 값인데 토큰이 없어 하드코딩되고 있었음
- 검사기 자체 버그 1건: 경로에 공백이 있으면(`07_1bigshot-radar 2`) `import.meta.url.pathname` 이 `%20` 을 남겨 **아무 파일도 스캔하지 않고 "통과"** 로 보였음. `fileURLToPath` 로 수정 + 스캔 0건이면 실패하도록 가드 추가
