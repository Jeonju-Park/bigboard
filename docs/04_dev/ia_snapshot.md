## 화면 맵 (M1 = 웹앱 MVP)
- W0 랜딩(첫 방문 1스크린) → W1 온보딩(관심종목→팔로우 추천→증권사 선택, 건너뛰기 가능)
- 탭: S1 홈 / S5 탐색 / S6 캘린더 / S7 랭킹 / S8 마이
- S1 홈: 세그먼트 [속보|팔로우] + 필터 칩(매수/매도/대형/예고) + 공시 카드(단가×수량=총액, micro 자막) → 카드 탭 = S2
- S2 피드 상세: ①거래 요약(단가×수량·거래일vs공시일·보고사유·보유 전→후) ②세부변동내역(접힘) ③인물 컨텍스트(12개월 타임라인+팔로우) ④종목 정보(전일종가·스파크라인 1M/3M/1Y·시총·PER·PBR·배당·52주·거래량) ⑤내부자 동향(90일 순매수+타 거래) ⑥예고 배너 ⑦거래 바로가기(증권사 아웃링크)+고지문+DART 원문+공유
- S3 인물 프로필: 유형 배지(내부자/공직자), 보유 현황, 거래 타임라인, [M2] 공직자 재산공개 연혁(신선도 라벨 필수)
- S4 종목: 종목 정보 블록 + 전체 내부자 거래 + 예고 + 종목 팔로우 + 거래 바로가기
- S5 탐색: 통합검색(종목/인물) + 인기 큰손(유형 필터) + 최근 본 항목
- S6 캘린더: 주간 스트립 + 예고 리스트(D-day, 좌측 4px ink 바)
- S7 랭킹: 순매수/순매도(7·30·90일) 레이스 바, [M2] 공직자 보유 랭킹
- S8 마이: 팔로우 관리 / 증권사 설정 / [M3] 알림 / 출처·고지
- [M2] S9 시즌 리포트(3월 재산공개)
- 공통: 고지문 규칙(BSR-CMN-01), 데이터 신선도 라벨(BSR-CMN-02), [M2] 공유 카드
