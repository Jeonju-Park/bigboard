1. 하이라이트를 없앤 자리 — 강조 체계 교체

마커가 사라지면 bx §3의 강조 규칙("weight 600 + marker 하이라이트")이 절반만 남는다. 대신 총액을 별도 줄로 승격시키고 숫자는 IBM Plex Mono의 굵기와 크기로만 세운다. 문장 안에서는 색도 배경도 쓰지 않는다.

이전 — 문장 안 하이라이트

보통주 12,000주를 주당 61,200원에, 총 7억 3,440만원.

한 문장에 강조가 셋. 시선이 세 번 끊기고, 정작 제일 중요한 총액이 나머지와 같은 무게다.

확정 — 승격 + 서체 대비

보통주 12,000주를 주당 61,200원에 매도.
7억 3,440만원총액

본문 숫자는 Mono 600 + ink로만 구분한다. 총액은 문장에서 빼내 22px Mono 700으로 세운다. 색은 하나도 쓰지 않았는데 위계가 더 명확하다.

새 강조 규칙 — 본문 안에서는 Numeric 서체 + weight 600 + ink가 최대치다. 배경·색·밑줄·크기 키우기 전부 금지. 더 강조해야 하면 그 값은 문장 밖으로 승격시킨다.
