## [프롬프트 A] 디자인 시스템 개정

```
기존에 만든 "큰손레이더" 디자인 시스템 스타일가이드를 개정해주세요.
서비스명·메인 컬러·강조 방식이 전부 바뀌었습니다.
첨부한 bx_designsystem_source_bigshot_radar.md(2026-07-31 갱신본)를 유일한 규칙으로 삼고,
brand_principles.md와 로고 이미지 3종을 함께 참조하세요.
single-file React+Tailwind, 안드로이드 모바일 360x800 기준입니다.

== 반드시 바꿔야 할 8가지 (기존 산출물에서 전부 틀림) ==

1. 서비스명: "큰손레이더" → "빅보드 / BIG board" 전면 교체.
   국문 "빅보드", 영문 병기는 "BIG board"(BIG 굵게 / board 가늘게).
   BigBoard, BIGBOARD, 빅 보드 표기 금지.

2. 메인 컬러: 방송 옐로우 #FFD338 → coral-500 #FF7355.
   옐로우는 열린우리당·노무현·정의당 상징색과 색차 dE 9.6(동일색 인지 구간)이라 폐기했습니다.
   스케일: coral-50 #FFF1ED / 100 #FFE2DA / 200 #FFCCBE / 300 #FFAC98 / 400 #FF8F74 / 500 #FF7355

3. coral은 "면"으로만 씁니다.
   흰 배경 위 대비가 2.68이라 선·아이콘·테두리·텍스트 색으로 쓰면 WCAG 1.4.11 위반입니다.
   coral 면 위에는 ink(#17191C)만 얹습니다(6.57:1). 흰 글자 금지(2.68).

4. coral-500은 브랜드 면, coral-300은 데이터 그래픽으로 사용처를 나눕니다.
   coral-500 = 히어로 블록, CTA 면, 활성 세그먼트·탭, 로고, 앱 아이콘
   coral-300 = 랭킹 1위 바
   이유: coral-500은 매수 레드 #D93B3B와 dE 18.7로 뭉칩니다. coral-300은 dE 45.4로 안전합니다.
   coral-400보다 진한 단계는 만들지 마세요 — 다시 충돌합니다.

5. 텍스트 마커 하이라이트를 전부 없애세요.
   문장 안 강조는 "Numeric 서체(IBM Plex Mono) + weight 600 + ink"가 최대치입니다.
   배경·색·밑줄·크기 키우기 전면 금지.
   더 강조할 값은 문장 안에서 키우지 말고 문장 밖으로 승격시킵니다.
   예: "보통주 12,000주를 주당 61,200원에 매도." 아래 별도 줄에 "7억 3,440만원" 22px Mono 700 + "총액" 라벨 11px.

6. ink는 브랜드 컬러가 아니라 글자·아이콘 색입니다.
   검은 앱바, 검은 히어로, 검은 배경 블록 전부 금지.
   예외는 앱 아이콘·파비콘 1곳뿐입니다(첨부 Fabicon.png 참조).

7. Display 서체는 Paperlogy 800으로 확정하되 사용을 최소화합니다.
   로고 워드마크 + 화면당 최대 1회의 display(24px/800)에만.
   title(20px/700) 이하 레벨은 전부 Pretendard입니다. 숫자는 전부 IBM Plex Mono + tabular-nums.
   화면 텍스트의 99%가 Pretendard가 되는 게 정상입니다.

8. 그라데이션 조항이 신설됐습니다.
   grad-sunset = linear-gradient(135deg, #FF7355 0%, #FFB964 100%) — 2스톱, 135도 고정.
   허용은 로고·랜딩 히어로·스플래시·OG·스토어 그래픽 5곳뿐.
   앱 UI 내부(카드·버튼·바·칩·배경 면)에는 절대 쓰지 마세요.

== 포함할 것 ==

1. Color: 위 토큰 전부 + 시맨틱(매수 #D93B3B / 매도 #2563A8, 변경 없음) + gray 9단계.
   각 컬러에 면적 예산(흰 배경 60 / secondary 28 / coral 12) 표기.
   "coral을 선·텍스트로 쓰면 안 되는 이유"를 대비값과 함께 명시.
2. Typography: 3서체 x 8스케일 스펙시먼. 각 스케일 옆에 어느 서체인지 라벨.
   계층 법칙 L1~L5를 실제 문장으로 시연 (L5 micro 예시: "3거래일 만인데 말이죠,")
   강조 규칙 Before/After 비교 1세트 — 마커 쓴 버전(잘못됨)과 승격 버전(맞음).
3. Spacing: 4pt 스케일 + 근접성 비율(내부:외부 최소 1:3) 시각화.
4. Tier 1 컴포넌트 7종: 공시 카드 / 티커 바 / 랭킹 로우 / 팔로우 칩 / 하단 탭 / 앱바 / 히어로 블록(coral 면).
   각각 사이즈 변형, 상태(default/pressed/disabled), 사용처 1줄.
   공시 카드는 실제 내용으로: "김OO · 대표이사 / OO전자 / 매도 태그 / 보통주 12,000주를 주당 61,200원에 매도. / 총액 7억 3,440만원 / micro: 3거래일 만인데 말이죠,"
5. 상태 4종(로딩/빈/에러/정상) 미니 데모.
6. 로고 사용 규칙: 첨부 이미지 3종을 배치하고 클리어스페이스(심볼 높이의 1/2), 최소 크기(심볼 16px / 락업 높이 24px), 금지 사용례 3개(임의 색 변경, 비율 왜곡, 그림자·테두리 추가).
7. Do & Don't: bx 문서 §8 체크리스트를 시각 예시로. 특히 "마커 쓰지 않기", "검은 면 쓰지 않기", "coral을 선으로 쓰지 않기" 3개는 반드시 포함.

== 하드 제약 ==
- 흰 배경 60% / 연회색 면 28% / coral 12%. 보라·인디고·다크 기본값·글래스모피즘 금지
- 앱 UI 내부 그라데이션 금지(로고·히어로 예외는 위 8번)
- Inter, Roboto 금지. Paperlogy(display만) + Pretendard(주력) + IBM Plex Mono(숫자)
- 최대 글자 24px, 화면당 display 1회 이하
- 이모지 금지, 아이콘은 Material Symbols Rounded만
- 카드 남발 금지: borderless + 헤어라인 디바이더 기본. 카드는 "공시 카드" 하나
- absolute 포지션은 티커 바 1곳만 허용(마커가 폐기되어 2곳에서 1곳으로 줄었습니다)
- 이미지는 전부 placehold.co placeholder + 라벨
- "추천·시그널·매수 타이밍·목표가·유망" 등 투자 판단 암시 워딩 전면 금지

== 산출 형식 ==
- 좌측 앵커 네비 + 섹션별 스타일가이드 페이지 1개
- 마지막 섹션에 CSS variables 전체를 복사 가능한 코드블록으로
- 각 결정에 "왜 이 선택인가" 주석 1줄 (첨부 문서 §번호 인용)
- 완성 후 bx 문서 §8 안티 AI 체크리스트를 항목별 통과 여부로 보고
```

### 검수 포인트 — 결과 받고 이것부터 확인

**coral이 텍스트나 선으로 쓰이지 않았는가.** 이게 가장 자주 어기는 항목이다. 링크·아이콘·보더에 coral이 들어가 있으면 되돌린다.

**마커가 정말 사라졌는가.** 옐로우에서 코랄로 색만 바꿔놓고 하이라이트 자체는 유지하는 경우가 많다.

**검은 면 블록이 없는가.** 앱바·히어로가 ink로 칠해져 있으면 안 된다.

**Paperlogy가 title 이하에 쓰이지 않았는가.** display 1곳과 워드마크 외에는 전부 Pretendard여야 한다.

**숫자에 tabular-nums가 걸렸는가.** 랭킹·티커에서 자릿수가 흔들리면 스코어보드 감성이 깨진다.

## [프롬프트 B] 화면 초안 (5화면)

```
첨부한 bx_designsystem_source_bigshot_radar.md(2026-07-31 갱신본)와
방금 개정한 디자인 시스템 토큰을 그대로 사용해,
"빅보드(BIG board)"의 5개 화면 초안을 single-file React+Tailwind 프로토타입으로 만들어주세요.
안드로이드 360x800, 상단에 화면 전환 토글(개발용, 최종 UI 아님)을 두세요.

== 화면 이름이 바뀌었습니다 ==
홈 → 속보 / 검색 → 탐색 / 캘린더 → 예고 / 랭킹 → 보드 / 마이 → 마이
하단 탭 라벨도 이 5개입니다. 이름은 방송국 어휘 풀(보드·속보·예고·중계·자막)에서 가져왔습니다.

== 화면 1: 속보 ==
사용자가 하루 3번 열어 "오늘 큰손이 뭘 했나"를 30초에 파악하는 화면.
- 앱바: 흰 배경 + 로고(심볼+워드마크). 검은 앱바 금지
- 히어로 블록: coral-500 면, radius 20, 좌우 마진 12
  · 라벨 "오늘 공시"(11px/700/opacity 0.68)
  · 큰 숫자 "37" — IBM Plex Mono 700, 58px, letter-spacing -0.045em, ink
    (이 숫자는 Paperlogy가 아니라 Mono입니다. 전광판 은유가 숫자에 있습니다)
  · 설명 1줄 "내부자 거래 37건이 오늘 판에 올랐습니다."
  · KPI 3칸(매수 14건 / 매도 23건 / 예고 D-6) — 흰색 반투명 면 위 Mono
- 티커 바: bg-secondary 알약형, 최신 공시가 흐름. 상시 모션은 여기만
- 세그먼트: [속보 | 팔로우] — 활성은 coral-200 면 + ink 글자
- 필터 칩: 전체/매수/매도/대형/예고 — 활성은 coral-100 면 + coral-200 보더
- 공시 카드 타임라인 (오늘 4건, 어제 3건 — 날짜 그룹 헤더는 title-s)
  각 카드 구조:
    · 아바타(coral-100 면 + ink 성씨 한 글자) + 이름·직함 + 소속 + 매수/매도 태그
    · 본문 1줄: "보통주 12,000주를 주당 61,200원에 매도." — 숫자만 Mono 600 ink, 하이라이트 없음
    · 총액 승격 줄: "7억 3,440만원" 22px Mono 700 ink + "총액" 라벨 11px gray-500
    · micro 자막 1줄 + 우측 날짜(Mono 11px)
- micro 자막 예시: "3거래일 만인데 말이죠," / "취임 후 첫 장내 매수입니다," / "예고했던 그 매도가 시작됐습니다,"
  (쉼표로 여운을 남기고 끝내는 게 이 브랜드의 어미입니다)

== 화면 2: 탐색 ==
- 검색 필드(bg-secondary 면) + 최근 검색
- "팔로우 중" 그룹: 인물 칩 리스트 (아바타는 coral-100 면 + 성씨)
- "많이 팔로우하는 큰손" 리스트: borderless 로우 + 헤어라인 디바이더

== 화면 3: 예고 ==
- 상단 title "예고" + 부제 "사전공시 제도 · 지분 1% 또는 50억원 이상 거래는 개시 30일 전 공시"
- 주간 스트립 캘린더: 선택일은 ink 면(작은 요소라 허용), 공시 있는 날은 coral 점
- 리스트: "D-6 | OO화학 박OO · 매도 예고 / 보통주 180,000주 · 개시 예정 08.06"
- D-day는 coral이 아니라 ink 또는 gray-700. 좌측 4px 세로 바로만 구분

== 화면 4: 보드 (랭킹) ==
- 상단 라벨 "7일 순매수" + title "이번 주 보드"
- 1위 하이라이트 블록: coral-500 면, radius 18 — "1위 / OO전자 / +842억"
  금액은 Mono 700 36px ink
- 기간 탭: 7일 / 30일 / 90일 — 활성은 coral-500 면 + ink 글자
- 랭킹 로우: 순위(Mono) + 종목 + 레이스 바 + 금액
  · 1위 바만 coral-300, 2위 이하는 gray-300. 트랙은 bg-secondary
  · 금액은 시맨틱 컬러(매수 #D93B3B / 매도 #2563A8)
  · 1위 바에 coral-500을 쓰지 마세요 — 매수 레드와 dE 18.7로 뭉칩니다
- 하단 micro: "1위는 아직 개표 중입니다만,"

== 화면 5: 마이 ==
- 알림 설정 그룹 / 팔로우 관리 / 증권사 설정 / 출처·고지
- 하단 고지문은 caption으로 반드시: "본 서비스는 투자 자문이 아니며, 공시 정보를 재가공한 참고 자료입니다."
- 공직자 데이터가 노출되는 곳에는 "연 1회 공개" 신선도 라벨 필수

== 공통 ==
- 하단 탭 5개(속보/탐색/예고/보드/마이), Material Symbols Rounded
  활성 탭은 coral-200 알약 면 + ink 아이콘. coral 아이콘 금지(선·아이콘 색 사용 불가)
- 앱바는 화면명 하나만. 흰 배경
- 각 화면에 상태 토글(정상/로딩/빈/에러) 포함
- 목데이터는 현실적인 한국 기업·직함·금액으로. 실존 기업명 금지 — OO전자, OO바이오 식
- 모든 숫자에 tabular-nums

== 하드 제약 ==
- 텍스트 하이라이트 0건. 강조는 Mono+600+ink 또는 문장 밖 승격
- 검은 면 블록 0건(앱 아이콘 제외). 앱바·히어로를 ink로 칠하지 말 것
- coral은 면으로만. 선·아이콘·테두리·텍스트 색 금지
- 앱 UI 내부 그라데이션 0건
- Paperlogy는 로고 워드마크와 화면당 1회 display에만
```
