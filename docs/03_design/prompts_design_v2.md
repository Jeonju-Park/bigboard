## [프롬프트] 1안 → v2 초안 변경 (복붙용)

```
기존 프로토타입을 첨부한 IA v0.2에 맞게 변경해주세요. 디자인 시스템 토큰·안티 AI 규칙(첨부 문서 §8)은 그대로 유지합니다.

== 변경 1: 홈 구조 (가장 큼) ==
- 상단 티커 바 제거. 대신 앱바 아래에 세그먼트 [속보 | 팔로우] (ink 밑줄 선택, 색면 금지)
- 속보 탭 = 전체 공시 피드 + 필터 칩 1줄(매수만/매도만/대형 10억+/예고)
- 팔로우 탭 = 팔로우한 인물·종목 공시만. 빈 상태: 안내 + "탐색에서 팔로우하기" 버튼 + micro 위트 1줄
- 상시 모션 요소가 사라졌으므로, 시그니처는 옐로우 마커 + micro 자막으로 유지 (새 모션 추가 금지)

== 변경 2: 공시 카드 정보 확장 ==
- 기존: 인물/방향/총액/경과시간/micro 자막
- 추가: 거래단가 × 수량 표기 — 총액 아래 Numeric caption으로 "78,400원 × 19,400주" 형태
- 총액에만 옐로우 마커. 단가×수량은 gray-500 caption (계층 위반 금지)

== 변경 3: 피드 상세 화면 신설 (신규 화면, 카드 탭 시 진입) ==
스크롤 1페이지, 섹션 간 40px, 섹션 제목은 title-s. 위에서부터:
1. 거래 요약: 방향 배지 / 단가×수량=총액 / 거래일 vs 공시일(시차 caption) / 보고사유 / 보유 변화(전→후 지분)
2. 세부변동내역: 접힌 테이블(일자·단가·수량), "펼치기" 텍스트 버튼
3. 인물 컨텍스트: 아바타 placeholder + 최근 12개월 미니 타임라인(점+선, 색은 시맨틱) + 누적 순매수 + 팔로우 버튼 + micro 자막
4. 종목 정보: 전일 종가·등락 / 스파크라인(1M·3M·1Y 토글) / 시가총액·PER·PBR·배당수익률·52주 최고최저·거래량 — 2열 정의 리스트(카드 금지, 디바이더)
5. 이 종목의 내부자 동향: 90일 순매수 미니 바 + 다른 거래 3건 리스트
6. 예고 배너(해당 시): "D-6 예고된 매도 50억" — 좌측 4px ink 바
7. 액션 영역: [거래 바로가기] Primary 버튼(ink 배경·흰 글자) + 바로 아래 caption 고지문
   "주문은 OO증권 앱에서 직접 진행됩니다 · 본 서비스는 투자 자문이 아닙니다"
   + 보조 텍스트 버튼: DART 원문 보기 / 공유
- 데이터 신선도 라벨을 각 블록 우상단 caption으로 ("전일 종가 기준" 등)

== 변경 4: 인물 유형 2종 ==
- 인물 관련 UI(팔로우 칩, 탐색 리스트, 인물 컨텍스트)에 유형 배지 추가: [내부자] / [공직자]
- 배지는 텍스트+헤어라인 보더만(색면 금지)
- 공직자 인물의 데이터 블록에는 반드시 "기준 2025.12.31 · 연 1회 공개" 라벨 고정
- 탐색 화면 인기 큰손 리스트에 유형 필터 칩(전체/내부자/공직자) 추가

== 변경 5: 온보딩 3스텝 신설 ==
관심종목 선택(칩) → 큰손 팔로우 추천 → 주거래 증권사 선택(라디오 리스트, 건너뛰기 가능)

== 유지 ==
탐색/캘린더/랭킹/마이 구조, 상태 4종 토글, 목데이터 톤(사실+micro 위트), 가상 기업명

== 완료 후 보고 ==
1. 안티 AI 체크리스트(§8) 항목별 통과 여부
2. 변경 4건이 계층 법칙(L1~L5)을 위반하지 않았는지 자체 점검 결과
3. 피드 상세의 섹션 순서에 대해 대안이 있다면 1개 (이유 포함)
```

## 검수 포인트 (결과 받고 확인)
- [ ] 세그먼트가 탭바처럼 보이지 않는가 (밑줄만, 배경 색면 없음)
- [ ] 단가×수량이 총액보다 시각적으로 약한가 (계층)
- [ ] 피드 상세가 카드 더미가 아니라 지면(디바이더+여백)으로 읽히는가
- [ ] 공직자 데이터에 신선도 라벨이 빠짐없이 붙었는가
- [ ] 거래 바로가기 버튼 옆에 고지문이 있는가 — **법적 필수**

## 이 결과물의 용도
클로드 디자인 v2 초안 = **피그마 작업의 참고 원본**. 여기서 픽셀 완성도를 추구하지 말 것 — 구조·계층·상태가 맞으면 통과. 완성도는 피그마(figma_guide.md)에서.
