## [프롬프트 1] 디자인 시스템 생성

```
첨부한 bx_designsystem_source_bigshot_radar.md 를 유일한 규칙으로 삼아,
"큰손레이더"의 디자인 시스템 문서를 인터랙티브 스타일가이드(single-file, React+Tailwind)로 만들어주세요.
안드로이드 모바일 360x800 기준입니다.

== 정체성 ==
컨셉: "진지한 공시 데이터를 개표방송처럼 중계한다". 데이터는 정색, 자막만 위트.
레퍼런스 톤: SBS 개표방송 그래픽의 경쾌함 x 토스증권의 정보 밀도. 단, 색은 문서의 60/30/10을 절대 준수.

== 포함할 것 ==
1. Color: 문서 §2의 토큰 전부. 각 컬러 옆에 "화면 면적 예산(60/30/10)"을 표기한 사용 규칙 포함
2. Typography: §3의 3서체 x 8스케일 전체 스펙시먼. 계층 법칙 L1~L5를 실제 문장 예시로 시연
   (L5 micro 자막 예시: "3거래일 만에 또 파셨습니다")
3. Spacing: §4의 4pt 스케일 + 근접성 비율(내부:외부 ≥ 1:3) 시각화
4. Tier 1 컴포넌트 7종: 공시 카드 / 티커 바 / 랭킹 로우(레이스 바) / 팔로우 칩 / 하단 탭 / 앱바 / 마커 하이라이트
   - 각 컴포넌트: 사이즈 변형, 상태(default/pressed/disabled), 사용처 1줄
   - 공시 카드는 실제 내용으로: "△△전자 CFO 김OO — 15.2억 매도 — 공시 후 2시간" + micro 자막 1줄
5. 상태 4종(로딩/빈/에러/정상) 미니 데모
6. Do & Don't 섹션: 문서 §8 안티 AI 체크리스트를 시각 예시(작게)로

== 하드 제약 ==
- 흰 배경 60% / 연회색 면 30% / 브랜드 컬러 10% 이하. 그라데이션·보라 계열·다크 배경·글래스모피즘 금지
- Inter, Roboto 사용 금지. Paperlogy(또는 Gmarket Sans) + Pretendard + IBM Plex Mono만
- 최대 글자 24px. 강조는 weight 600 + 옐로우 마커 하이라이트로만
- 이모지 금지, 아이콘은 Material Symbols Rounded만
- 카드 남발 금지: borderless + 헤어라인 디바이더 기본. 카드는 "공시 카드" 단 하나
- 요소 겹침 금지: absolute 포지션은 티커 바·마커 하이라이트 외 사용 금지
- 이미지는 전부 placehold.co placeholder + 라벨

== 산출 형식 ==
- 좌측 앵커 네비 + 섹션별 스타일가이드 페이지 1개
- 마지막 섹션에 CSS variables 전체를 복사 가능한 코드블록으로
- 각 결정에 "왜 이 선택인가" 주석 1줄 (첨부 문서 §번호 인용)
```

**검수 포인트 (결과 받고 확인)**: ①마커 옐로우가 텍스트 색으로 쓰이지 않았는가 ②micro 레이어 외 위트 없음 ③display 남용 없음 ④§8 체크리스트 전 항목.

## [프롬프트 2] 화면 초본 (5화면)

```
첨부한 bx_designsystem_source_bigshot_radar.md 와 방금 확정한 디자인 시스템 토큰을 그대로 사용해,
"큰손레이더"의 5개 화면 초본을 single-file React+Tailwind 프로토타입으로 만들어주세요.
안드로이드 360x800, 상단에 화면 전환 토글(개발용, 최종 UI 아님)을 두세요.

== 화면 1: 홈 피드 ==
사용자가 하루 3번 열어 "오늘 큰손이 뭘 했나"를 30초에 파악하는 화면.
- 상단: 티커 바 (최신 공시 3건이 흐름 — 시그니처 요소, 여기만 상시 모션)
- 본문: 공시 카드 타임라인 (오늘 4건, 어제 3건 — 날짜 그룹 헤더는 title-s)
- 각 카드: 인물명+직함 / 방향(매수 레드·매도 블루) / 금액(Numeric, 핵심 숫자에 옐로우 마커) / 경과시간 / micro 자막 1줄
- micro 자막 예시 데이터: "올해만 세 번째 매도입니다" / "취임 후 첫 매수네요" / "예고했던 그 매도가 시작됐습니다"

== 화면 2: 검색·팔로우 ==
- 검색 필드(bg-secondary 면) + 최근 검색
- "팔로우 중" 그룹: 인물 칩 리스트 (placeholder 아바타 1:1)
- "많이 팔로우하는 큰손" 리스트: borderless 로우 + 디바이더

== 화면 3: 예고 캘린더 ==
- 주간 스트립 캘린더 + 하단 리스트: "D-6 | ◇◇바이오 대표 — 예고 매도 50억"
- 예고 건은 좌측에 4px ink 세로 바로만 구분 (색면 금지)

== 화면 4: 랭킹 ==
- 세그먼트 탭: 순매수 / 순매도 (탭 선택은 ink 밑줄, 색면 금지)
- 랭킹 로우: 순위(Numeric) + 종목 + 레이스 바(시맨틱 컬러, 높이 6px) + 금액
- 1~3위만 weight 700, 마커 하이라이트. 개표방송의 "당선 유력" 느낌은 크기가 아니라 굵기와 마커로

== 화면 5: 마이 ==
- 알림 설정 그룹 / 팔로우 관리 / 고지문
- 하단 고지문은 caption으로 반드시 포함: "본 서비스는 투자 자문이 아니며, 공시 정보를 재가공한 참고 자료입니다."

== 공통 ==
- 하단 탭 5개 (Material Symbols Rounded), 앱바는 화면명 title 하나만
- 각 화면에 상태 토글(정상/로딩/빈/에러) 포함
- 목데이터는 위 예시처럼 현실적인 한국 기업·직함·금액으로 (실존 기업명은 쓰지 말고 △△전자, ◇◇바이오 식)
- "추천·매수하세요" 류 워딩 절대 금지 — 사실 서술만

== 하드 제약 ==
[프롬프트 1]과 동일: 60/30/10, 서체 3종, 24px 상한, 이모지 금지, borderless 기본,
absolute 금지(티커·마커 제외), placeholder 이미지, 요소 겹침 금지.
완성 후 스스로 안티 AI 체크리스트(첨부 문서 §8)를 항목별 통과 여부로 보고해주세요.
```
