# 빅보드(BIG board) 디자인 시스템 소스 문서 — "개표방송 스튜디오"
> 2026-07-31 서비스명 확정: 큰손레이더(가칭) → **빅보드 / BIG board**. 이 문서 내 "큰손레이더" 표기는 전부 "빅보드"로 읽는다.

> 이 문서가 단일 진실(Single Source of Truth). 클로드 디자인·클로드 코드 프롬프트는 전부 이 문서를 인용한다.
> 컨셉 승인 전까지 모든 값은 v0.1 제안.

## 0. 디자인 방향 선언 (한 줄)
**"진지한 공시 데이터를 개표방송처럼 중계한다"** — 데이터는 정색, 자막은 위트.
유쾌함의 출처는 색·장식이 아니라 ①마이크로 카피(하단자막) ②순위 레이스 연출 ③형광펜 하이라이트 3가지로 한정한다.

## 1. 브랜드 컨셉 (BX)
- 스테이트먼트: **"공시를 못 읽는 사람들 앞에서, 큰손들의 판을 개표방송처럼 중계한다."** (`brand_principles.md` §1)
- 톤 키워드: **witty(위트), factual(팩트), brisk(경쾌한 속보감), unbothered(호들갑 없음)**
- 페르소나: "농담은 하지만 숫자는 절대 안 틀리는 개표방송 캐스터"
- 보이스 DO / DON'T:
  - DO: "3거래일 만에 또 파셨습니다" / "예고된 매도, D-6" — 사실 + 절제된 위트
  - DON'T: "지금 사야 할 종목!" (법적 금지), "대박" "폭탄" 류 과장, 이모지 전부. 금지어 전체 목록은 `brand_principles.md` §5
- 위트의 자리: 오직 **micro 캡션(11px)** 레이어에서만. 제목·본문·숫자는 항상 정색.
- 위트는 **인물이 아니라 상황**을 향한다 — 실명 인물을 다루므로 인물 조롱은 명예훼손 리스크다.

**로고 (2026-07-31 확정)**
심볼 = B의 stem을 coral로 세운 형태. 워드마크 = **BIG board**(BIG 굵게 / board 가늘게). 파일: `assets/brand/logo/`
앱 아이콘·파비콘은 ink 면 위 흰 B + coral stem — **§8의 "검은 면 금지"에서 유일하게 예외**다.

## 2. 색상 — 60 / 30 / 10 법칙 (화면 면적 기준)

> **2026-07-31 확정.** 메인 = 코랄 `#FF7355`. **ink는 브랜드 컬러가 아니라 글자·아이콘 색이다.** 텍스트 하이라이트(마커)는 전면 폐기. 폐기 이력: 방송 옐로우 #FFD338(정의·노무현 노랑과 dE 9.6 — 정치색), 민트·스프링그린(톤), 진한 탠저린 #FF6938(매수 레드와 dE 22.9 — 간섭), 라이트 탠저린 #FFD0BD(과도하게 연함). 비교 시안: `color_list.html` · `bigboard_coral_preview.html`

| 역할 | 면적 | 토큰 | HEX | 용도 |
|---|---|---|---|---|
| Base | ~60% | `bg-primary` | #FFFFFF | 모든 화면 기본 배경 |
| Sub | ~28% | `bg-secondary` | #F6F7F8 | 그룹 구분 면, 입력 필드, 티커 바 |
| | | `gray-200` | #E9EBED | 헤어라인 디바이더 (1px) |
| **Main** | ~12% | `coral-500` | **#FF7355** | **브랜드 면 전용** — 히어로, CTA, 활성 세그먼트·탭, 로고, 앱 아이콘 |
| Data | ≤3% | `coral-300` | **#FFAC98** | 데이터 그래픽 — 랭킹 1위 바 |
| Text | — | `ink` | #17191C | **글자·아이콘 색.** 브랜드 컬러가 아니다 |

**Coral Scale (Lab-H 40 고정)**
| 토큰 | HEX | L* | C* | 흰 배경 위 | ink 대비 | dE 매수레드 | 용도 |
|---|---|---|---|---|---|---|---|
| `coral-50` | #FFF1ED | 96 | 5 | 1.10 | 15.98 | 80.6 | 아주 연한 면 |
| `coral-100` | #FFE2DA | 92 | 12 | 1.22 | 14.38 | 73.3 | 칩·아바타 |
| `coral-200` | #FFCCBE | 86 | 21 | 1.44 | 12.27 | 62.2 | 선택 상태 |
| `coral-300` | #FFAC98 | 78 | 36 | 1.81 | 9.73 | **45.4** | 랭킹 1위 바 |
| `coral-400` | #FF8F74 | 71 | 52 | 2.23 | 7.91 | 30.2 | 호버 |
| `coral-500` | **#FF7355** | 65 | 67 | 2.68 | **6.57** | 18.7 | **브랜드 기본** |

**사용 규칙 (위반 시 접근성·의미 오독)**
- **coral은 면으로만 쓴다.** 흰 배경 위 대비 2.68이라 선·아이콘·테두리·텍스트 색으로 쓰면 WCAG 1.4.11(비텍스트 3:1) 위반이다.
- **coral 면 위에는 ink만 얹는다** (6.57, 본문 크기까지 AA). 흰 글자는 2.68이라 금지.
- **데이터 그래픽에는 coral-500을 쓰지 않는다.** 매수 레드와 dE 18.7로 뭉친다. 랭킹 1위 바는 `coral-300`(dE 45.4). 즉 **coral-500 = 브랜드, coral-300 = 데이터**로 사용처가 갈린다.
- coral-400 이하 진한 단계는 만들지 않는다 — 매수 레드와 dE 30 이하로 다시 충돌한다.

**시맨틱 (국장 관습 — 변경 불가)**
- 매수/상승 `semantic-buy` #D93B3B / 매도/하락 `semantic-sell` #2563A8 — **변경 없음**
- 시맨틱 컬러는 숫자·태그에만. 배경 면으로 쓰지 않는다.

**ink 사용 범위 (신설)**
글자·아이콘 색, 그리고 랜딩 CTA 면 1곳만 예외. **검은 앱바·검은 히어로·검은 마커는 금지** — 무게가 과해 브랜드 톤(경쾌한 속보감)과 어긋난다.

**Gray Scale 9단계**: 50 #FAFBFC / 100 #F6F7F8 / 200 #E9EBED / 300 #D6DADD / 400 #B0B6BC / 500 #8A9199 / 600 #5F666E / 700 #3F454C / 800 #26292E / 900 #17191C

**금지(안티 AI 팔레트)**: 보라·인디고 계열 일체, 그라데이션 배경, 다크모드 기본값, 네온 온 다크, 글래스모피즘, 카드 글로우. (근거: 하단 §8 출처)

**정치색 회피 규칙 (신설)**: 현역 정당 상징색 — 국민의힘 빨강 · 더불어민주당 파랑 · 정의당·노무현 노랑 · 개혁신당 주황 · 진보 보라 — 과 CIE76 dE 35 미만인 색은 브랜드 컬러로 채택하지 않는다. 이 서비스는 개표방송을 은유하고 고위공직자 데이터를 다루므로 색 하나가 편향 신호로 읽힌다. 출처: [색(色)의 정치 — AODR](https://www.aodr.org/_PR/view/?aidx=35853&bidx=3213) · [한국일보](https://www.hankookilbo.com/News/Read/A2024020522220001992) (2026-07 확인)

> 잔여 리스크 — accent-600 #018346은 소멸 정당인 국민의당(2016) 초록과 dE 27.4, 녹색당 진초록[추정]과 dE 18.2로 가깝다. 다만 둘 다 원내 존재감이 없고, 액센트는 3% 예산의 작은 UI 요소(1위 바·활성 상태)에만 쓰이며 브랜드 인상은 ink가 지배하므로 수용 가능하다고 판단했다.

명도대비: 본문 gray-800 on white = 13:1+, 캡션 gray-500 on white ≈ 4.6:1 (AA 통과). 마커(ink 면) 위 텍스트는 흰색만 허용 = 17.61:1.

## 3. 타이포그래피 — 3서체 역할 분리 (Inter/Roboto 기본값 회피)

> **2026-07-31 확정.** Display = Paperlogy (SIL OFL 1.1). Gmarket Sans 탈락 — 라이선스는 동일하나 weight가 3종(300·500·700)뿐이라 타입 스케일이 요구하는 600·800이 없고, woff2 파일이 2배 이상 무겁다. 근거: `assets/brand/fonts/README.md`

| 역할 | 서체 | 사용 범위 | 이유 |
|---|---|---|---|
| Display | **Paperlogy** 800 | **로고 워드마크 + 화면당 최대 1회 display(24px). 그 외 전면 금지** | 방송 자막·포스터의 각진 존재감. 최소 노출로 브랜드 시그니처만 담당 |
| Body | **Pretendard** | **제목·본문·라벨·캡션·micro 전부** — 화면 텍스트의 사실상 전량 | 한글 UI 가독성 표준 |
| Numeric | **IBM Plex Mono** (tabular) | 모든 숫자. `font-variant-numeric: tabular-nums` 필수 | 스코어보드 감성 + 자릿수 정렬. Roboto Mono 회피 |

**Paperlogy 최소 사용 원칙**: title(20px/700) 이하 레벨에 Paperlogy를 쓰지 않는다. 웹폰트도 800 한 종(약 155KB)만 로드한다. Display 서체가 흔해지면 "각진 존재감"이 존재감이 아니게 되고, 모바일 초기 로딩만 무거워진다.

**타입 스케일 (큰 글자 지양 — 최대 24px)**
```
micro   11px / 400 / gray-400   ← 위트 자막 전용 레이어 (꾸밈 허용)
caption 12px / 400 / gray-500
body-s  13px / 400 / gray-700
body    15px / 400 / gray-800   (base)
label   15px / 600 / ink
title-s 17px / 600 / ink
title   20px / 700 / ink
display 24px / 800 / ink        ← 화면당 1회 이하
행간: 본문 1.5 / 제목 1.25 / 숫자 1.2
```

**계층 법칙 (레벨마다 굵기·크기·색 3요소를 동시에 규정 — 임의 조합 금지)**
- L1 화면 제목: display 또는 title, weight 700+, ink
- L2 섹션/그룹 제목: title-s, 600, ink
- L3 본문: body, 400, gray-800
- L4 보조 설명: caption, 400, gray-500
- L5 위트 자막: micro, 400, gray-400 (여기만 유머 허용)
- 강조: **Numeric 서체 + weight 600 + ink**가 본문 안 최대치다. 배경·색·밑줄·크기 키우기 전면 금지.
  더 강조해야 하는 값은 문장 안에서 키우지 말고 **문장 밖으로 승격**시킨다 (예: 총액을 별도 줄에 22px Mono 700).

> **2026-07-31 — 텍스트 마커 하이라이트 폐기.** 문장 안 강조가 셋 이상 겹치면 시선이 끊기고, 정작 중요한 값이 나머지와 같은 무게가 된다. 승격 방식이 색을 하나도 쓰지 않고도 위계가 더 명확했다. 근거 시안: `bigboard_coral_preview.html` §1

## 4. Spacing & 그룹핑 — 4pt 그리드 + 근접성 비율
```
스케일: 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48
```
- **근접성 법칙**: 관련 요소 간격 ≤ 8px, 그룹과 그룹 사이 ≥ 24px, 섹션 사이 ≥ 40px. **내부:외부 간격 비율 최소 1:3** 유지 → 그룹핑이 선 없이도 읽히게.
- 화면 좌우 여백 20px 고정. 터치 타깃 최소 44pt.
- **겹침 금지 검증 규칙**: 절대 위치(absolute) 사용은 티커 바 1곳만 허용(마커 폐기). 그 외 전부 플로우 레이아웃. 컴포넌트는 min-height와 padding으로 자체 공간 확보.

## 5. 컴포넌트 원칙 — "카드를 줄이고 지면처럼"
- **기본은 borderless**: 리스트는 헤어라인 디바이더(gray-200 1px)와 여백으로 구분. 신문 지면처럼.
- 카드 허용 조건 (전부 충족 시에만): ①독립적으로 탭 되는 단위 ②공유/캡처되는 단위. → 사실상 "공시 카드" 하나만 카드다. radius 12px, 그림자 대신 gray-200 보더 또는 bg-secondary 면.
- Tier 1 컴포넌트: 공시 카드 / 티커 바(상단 속보) / 랭킹 로우(레이스 바 포함) / 팔로우 칩 / 하단 탭 / 앱바 / **히어로 블록(coral 면)**
- ~~마커 하이라이트 텍스트~~ — 폐기 (§3 참조)
- **시그니처 요소 1개**: "개표방송 티커" — 상단 고정 1줄, bg-secondary 면 + Numeric 서체로 최신 공시가 흐름. 유일하게 움직이는 상시 요소.
- 모션: 티커 흐름 + 랭킹 레이스 바 채워지는 200ms ease-out, CTA 탭 스케일. 그 외 등장 애니메이션(일괄 fade-in) 금지.

## 6. 아이콘·이미지
- 아이콘: **Material Symbols Rounded**, 20/24px, weight 400, 색은 ink 또는 gray-500. 이모지·이모티콘 전면 금지.
- 이미지: 전부 placeholder 규격화 — `https://placehold.co/{w}x{h}/F6F7F8/8A9199?text={LABEL}` + 고정 비율(프로필 1:1, 배너 16:9). 코드에서는 `<Placeholder label size>` 단일 컴포넌트로 감싸 교체 용이하게.

## 8. 안티 AI 체크리스트 (산출물 검수 게이트)
생성된 모든 화면은 아래 전 항목 통과해야 함:
- [ ] 보라/인디고, 글래스모피즘, 다크 기본값 없음
- [ ] Inter·Roboto 미사용 (지정 3서체만)
- [ ] "아이콘+제목+설명 3카드 그리드" 패턴 없음
- [ ] 모든 카드에 동일한 1px 회색 보더 + 그림자 조합 없음 (borderless 기본)
- [ ] 전 요소 일괄 fade-in 없음
- [ ] **앱 UI 내부에 그라데이션 없음** (아래 그라데이션 조항 참조)
- [ ] 메인 컬러 면적 12% 내외 / 화면당 display 1회 이하 / Paperlogy는 워드마크와 display에만
- [ ] **텍스트 하이라이트(마커) 없음** — 강조는 Numeric+600+ink 또는 승격
- [ ] **검은 면(ink 배경 블록) 없음** — 앱 아이콘·파비콘만 예외
- [ ] coral이 선·아이콘·테두리·텍스트 색으로 쓰이지 않았는가 (면 전용)
- [ ] 요소 겹침 없음 (스크롤 끝까지 확인)
- [ ] 위트는 micro 레이어에만 존재

**그라데이션 조항 (2026-07-31 신설)**

## 9. 결정 이력 / 미결정 사항

**9-1. 메인 컬러 — 확정 (2026-07-31)**
메인 = `ink` #17191C 무채색, 액센트 = 스프링그린(accent-600 #018346 / accent-300 #86DFA2). 마커 하이라이트는 색면이 아니라 ink 면 + 흰 글자로 처리한다. 상세는 §2. 폐기된 후보: 방송 옐로우 #FFD338(정치색 dE 9.6), 민트 #3ECFB2·#7FCEBE(형광끼·톤), 오렌지 #FF7A3D(매수 레드와 dE 28.2 간섭), 라임·코랄·터쿼이즈·핑크 등 8종(`color_list.html` 참조).

**9-2. 서비스명 — 확정 (2026-07-31)**
**빅보드 (Big Board)**. 오픈이슈 O7 해소. 근거·후보 비교는 `brand_principles.md` §0.

**9-3. Display 서체 — 확정 (2026-07-31)**
**Paperlogy 800**, 사용 범위는 로고 워드마크 + 화면당 1회 display로 최소화. 본문 주력은 Pretendard. 당초 가정("임베딩 조항이 결정 요인")은 성립하지 않았다 — Paperlogy와 Gmarket Sans 모두 SIL OFL 1.1로 임베딩·BI/CI 허용 범위가 동일했다. 실제 결정 요인은 weight 커버리지(9종 vs 3종)와 파일 크기(155KB vs 350KB/weight)였다. 상세: `assets/brand/fonts/README.md`

60/30/10 화이트 원칙 우선. v2 백로그. 단 메인이 ink 무채색으로 확정되면서 다크 전환 비용은 기존 대비 낮아졌다 — v2 검토 시 액센트만 accent-300으로 승격하면 된다.
