# 연관 아이디어 풀 (같은 데이터·같은 정서에서 파생)

> 큰손레이더가 PSF 실패하거나, 성공 후 확장할 때의 후보. 전부 "공개 데이터 재가공 = 라이선스 불요" 원칙 유지.

## A. 같은 데이터, 다른 앵글
1. **여의도장부** — 정치인 재산공개 전용 미디어/뉴스레터. 연 1회 데이터지만 3월 시즌 화력 극대화 + 연중 "의원 발의법안 × 보유주식 이해충돌" 매칭 콘텐츠. BM: 뉴스레터 스폰서십. (매매내역 신고제 입법 시 앱으로 승격하는 옵션 보유)
2. **연금이형** — 국민연금 5%룰 공시 트래커. "국민연금이 이번 달 산 것/판 것". 타겟: 장기투자자. 킬러: 연기금 순매수 랭킹.
3. **소각레이더** — 3차 상법 개정(자사주 1년 내 소각 의무화, 2026.2 통과) 대응. 자사주 취득·소각 일정 캘린더 + 알림. 신규 제도 = 경쟁 공백, 주주환원 테마와 정합.
4. **공매도워치** — 공매도 잔고·대차잔고 급증 알림. (데이터 출처·시차 확인 필요)

## B. 같은 정서(정보 비대칭 분노), 다른 도메인
5. **K-스톡법 카운터** — "국회의원 매매내역 공개법" 입법 추적 + 서명/청원 연계 시민 캠페인 사이트. 수익 아닌 브랜드/선점용. 법 통과 시 큰손레이더가 1번으로 붙는 포석.
6. **미국 정치인 트래커 한국어판** — Capitol Trades류 데이터의 한국어 큐레이션 (서학개미 타겟). 데이터 라이선스 비용 확인 필요. 국내 규제 관점에서는 정보 서비스로 동일하게 A레벨 [추정 — 해외 데이터 재판매 약관 검토 필요].

## C. 기존 파이프라인과의 시너지
7. "권리회복" 앱 클러스터(야근증인 등)와 동일한 포지셔닝 문법 — "제도는 있는데 개인이 못 쓰는 데이터를 개인의 무기로". 브랜드 우산 하나로 묶는 옵션.
