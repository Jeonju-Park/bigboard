> 01_IDEATION_GUIDE §2·§7 템플릿 준수. 작성일 2026-07-30, v0.1

## 1) 한줄 소개
상장사 내부자(임원·대주주)와 큰손의 매매 공시를 5일 내 알림·랭킹으로 보여주고, 대형 거래는 30일 전에 예고해주는 공시 레이더 앱.

## 2) 아이디어 배경
- 원안: 미국 Autopilot(정치인·헤지펀드 카피트레이딩, 운용자산 $2.4B+, 투자자 25만+ — 출처: Autopilot 스토어 설명, 유저 제공)
- 2026.7 코스피 폭락(일 -10.8%, 이틀 연속 서킷브레이커 — 출처: https://v.daum.net/v/20260729182310005) + "내부자/정치인은 미리 알았다" 정서 → 정보 비대칭 해소 수요 급증
- 한국은 정치인 거래 데이터가 없어(연 1회 스냅샷) 내부자 공시(5일/30일 전)로 피벗
- 근거 데이터: 01_research/ 3개 문서

## 3) 누구의 어떤 문제를 해결하는가
- **메인 타겟**: 주 3회 이상 MTS를 열어보는 20~40대 직접투자자 중, 공시를 봐야 한다는 건 알지만 DART 원문을 읽지 않는(못 읽는) 사람
- **JTBD**: "보유/관심 종목에서 큰손이 움직였을 때, 뉴스보다 먼저, 원문 안 읽고도, 그게 나에게 무슨 의미인지 알고 싶다."
- **hire/fire**: 현재 hire = 종목토론방·유튜브·지인 카톡방(늦고 부정확) / fire = DART 원문(어렵고 시끄러움), 증권사 공시알림(필터 없이 전부 쏟아짐)

## 4) 구체적 설명과 차별점
- **킬러 기능 1개**: 내부자·5% 매매 공시를 "누가/방향/규모/평단대비" 한 장 카드로 변환 + 관심종목·관심인물 푸시 (공시→푸시 목표 15분 내)
- 보조 기능:
  1. **예고 캘린더**: 30일 사전공시 기반 "다음 주 예고된 대량 매매" (신규 제도라 경쟁 공백 [추정 — competitor_scan으로 검증])
  2. **큰손 랭킹**: 최근 30일 내부자 순매수/순매도 상위 종목·인물
  3. **정치인 시즌 리포트**: 연 1회(3월) 의원 포트폴리오 변화 콘텐츠
- **차별점 1줄**: "공시 알림"이 아니라 "**사람(내부자)을 팔로우**하는 앱 — 종목 중심이 아닌 인물 중심 UX"
- 비목표: 자동매매(v3까지 금지), 시세/차트(MTS가 함), 커뮤니티(v1 제외)

## 5) 어떻게 실현하면 좋을지
- MVP 화면 5개: ① 홈 피드(공시 카드 타임라인) ② 종목/인물 검색·팔로우 ③ 예고 캘린더 ④ 랭킹 ⑤ 마이(알림 설정)
- MVP에서 빼는 것: 자동매매, 커뮤니티, 백테스트, 해외 데이터
- 예상 개발 기간: 수집 파이프라인 1주 + 앱 2~3주 [추정, Claude Code 기준]

## 6) 도메인 / TAM·SAM·SOM (Bottom-up)
- 도메인: 금융/IT
- TAM: 국내 주식 활동계좌 기반 직접투자자 약 1,400만 명 [추정 — (명확하지 않은 출처), KRX 통계로 검증 필요] × 정보서비스 연 지불의사 2만원 [추정] ≈ 2,800억
- SAM: 공시를 의식하는 액티브 투자자 15% [추정] ≈ 420억
- SOM (1~2년): SAM의 1~2% ≈ 4~8억 (MAU 3~6만 × ARPU 1.3만) [추정]
- ⚠️ 전 수치 검증 전 가설. KOSIS/KRX/금투협 통계로 교체할 것.

## 7) 참고 레퍼런스 검색 키워드
- 한글: 내부자 매매 공시, 임원 주식 매도 알림, 5%룰, 대주주 지분 변동, 공시 알림 앱
- 영어: insider trading tracker, insider buying alert, Form 4 tracker (미국 대응물), congress trading tracker
- 사이트: openinsider.com (미국 Form4 트래커 — UX 벤치마크 최우선), Capitol Trades, QuiverQuant

## 8) 경쟁사
- 직접: DART 알림, 증권사 MTS 공시알림, 플레이스토어 공시알림 앱들 → **competitor_scan.md 실사 전 미확정**
- 간접: 종목토론방, 공시 해설 유튜브/뉴스레터, 텔레그램 속보방

## 9) 수익 모델 · 그로스 1차 가설
- **주 BM**: 프리미엄형(Freemium) — 무료: 관심종목 3개 알림 + 일간 랭킹 / 유료(월 4,900원 [추정]): 무제한 팔로우, 예고 캘린더, 실시간 푸시, 주간 리포트
- 보조 BM: 광고형(AdMob, 무료 티어)
- 핵심 지표: 무료→유료 전환율 (3~5% 기준, 10%+ 우수)
- **North Star (가설)**: 주간 알림 확인(오픈) 수
- Input Metrics: 팔로우 등록 수/유저, 푸시 오픈율, D7 리텐션, 카드 공유 수
- **주력 Growth Loop**: Content — 공시 이벤트 → 자동 생성 공유 카드(이미지) → SNS/커뮤니티 유통 → 신규 유입. 3월 정치인 재산공개 시즌은 연 1회 대형 콘텐츠 스파이크.
- 1차 채널 가설: ① ASO 롱테일("내부자 매매", "공시 알림") ② 주식 커뮤니티/디스콰이엇 런칭 ③ 공시 해설 숏폼
- 리텐션 리트머스: 본인이 월 5회 이상 쓸 앱인가 → 보유종목 있으면 Yes (폭락장일수록 사용 ↑)

## 10) 사용자 시나리오
1. 첫 사용: 온보딩에서 보유종목 3개 입력 → 즉시 "이 종목의 최근 내부자 매매 히스토리" 카드 → 아하 순간 = "몰랐던 임원 매도가 있었네"
2. 재방문: 푸시("삼성전자 임원 A, 15억 매도 공시") → 카드 확인 → 관련 인물 팔로우
3. 공유: 폭락일에 "이 회사 임원들 지난달에 다 팔았음" 카드 캡처 → 커뮤니티 확산
