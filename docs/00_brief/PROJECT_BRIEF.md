# PROJECT BRIEF: 큰손레이더 (가칭 / slug: bigshot-radar)

> 작성일: 2026-07-30 | 버전 v0.1 | 상태: 아이디어 확정 전 (네이밍 미확정)

## 0. 한 줄
**"내부자가 사고팔면 5일 안에, 대형 거래는 30일 전에 알려주는 공시 레이더 앱."**
미국 Autopilot/PelosiTracker의 한국 버전을 만들려다, 한국 데이터 현실에 맞게 피벗한 결과물.

## 1. 원안 → 피벗 논리 (왜 정치인이 아니라 내부자인가)

| | 미국 (Autopilot 원형) | 한국 현실 |
|---|---|---|
| 정치인 거래 공시 | STOCK Act: 거래 건별 45일 내 공시(PTR) | **연 1회 잔액 스냅샷만** (12/31 기준 → 익년 3월 말 공개, 거래내역 없음) |
| 자동매매 실행 | SEC 등록 RIA(Autopilot Advisers)가 수행 | 투자일임업 등록 필요(자기자본·인력 요건, 미등록 시 형사처벌) |
| 증권사 연동 | 브로커리지 API 개방적 | 오픈API 고객서비스 제휴는 제도권 금융사(일임·자문업자)만 가능 |

→ **정치인 실시간 카피트레이딩은 데이터·라이선스 이중으로 막힘.**

그러나 한국에는 대체재가 있음:
- **임원·주요주주 특정증권등 소유상황보고**: 변동일부터 **5영업일 내** DART 공시 (자본시장법 §173)
- **내부자 거래계획 사전공시**: 지분 1% 또는 50억원 이상 거래는 **개시 30일 전** 공시 — 미국에도 없는 선행 데이터
- **5% 대량보유보고(5%룰)**: 5영업일 내
- 모두 **DART OpenAPI로 무료** 수집 가능

→ 킬러 컨셉: **"내부자보다 늦게 알지 말자"** — 공시를 사람이 읽을 수 있는 카드/알림으로 변환.

## 2. 정치인 데이터의 위치
- 연 1회 국회공보 재산공개(3월)는 **콘텐츠/미디어 축**으로 활용: "의원 포트폴리오 랭킹", "1년 새 뭘 샀나" 등 바이럴 콘텐츠 소재. 정보공개센터(cfoi.or.kr)가 스프레드시트로 가공 배포 중 — 파싱 부담 낮음.
- **입법 모니터링**: 경실련 등이 '주식 매매내역 신고제' 도입 촉구 중(이춘석 사건 이후). 통과되는 순간 PelosiTracker 모델이 한국에서 열림 → 그날 가장 빨리 붙일 수 있는 포지션을 미리 확보하는 것이 이 프로젝트의 장기 옵션 가치.

## 3. 법적 포지셔닝 (절대 원칙)
1. v1은 **공시 데이터 뷰어/알림** — 투자판단 조언 아님. "추천/시그널/매수하세요" 워딩 금지.
2. 모든 화면에 "본 서비스는 투자 자문이 아니며, 공시 정보를 재가공한 참고 자료입니다" 고지.
3. 유료화 확장 시 유사투자자문업 신고 검토 (단방향 원칙, 1:1 상담 금지).
4. 자동매매(v3)는 투자일임업 등록사 제휴 또는 규제 샌드박스 전까지 착수 금지.
