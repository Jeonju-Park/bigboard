# 법률 타당성: 한국판 Autopilot이 넘어야 할 규제

> 조사일: 2026-07-30 | 모든 항목 출처 명시. 법령은 개정 가능하므로 실행 전 재확인 필수.
> ⚠️ 본 문서는 참고용 정리이며 법률 자문이 아님. 유료화·연동 단계 진입 전 자본시장 전문 변호사 검토 1회 필수.

## 1. 자동매매(카피트레이딩) = 투자일임업

- 정의: 투자자로부터 투자판단의 전부/일부를 일임받아 투자자별로 금융투자상품을 취득·처분·운용하는 영업 (자본시장법 §6⑧)
- 등록: 금융위원회 등록 필수. 등록업무 단위별 1억원 이상(시행령 별표3 금액)의 자기자본 + 투자권유자문인력/투자운용인력 요건 (자본시장법 §18)
- 미등록 영업: **3년 이하 징역 또는 1억원 이하 벌금**
- 출처: 찾기쉬운 생활법령정보 https://www.easylaw.go.kr/CSP/CnpClsMainBtr.laf?popMenu=ov&csmSeq=572&ccfNo=2&cciNo=2&cnpClsNo=1 (2026-07 확인)

→ **결론: v1~v2에서 자동매매 절대 금지. v3 옵션 = ①등록 일임업자(핀트·파운트류) 제휴 ②금융규제 샌드박스 ③직접 등록(비현실적).**

## 2. 정보 제공의 경계선 3단계

| 레벨 | 행위 | 규제 |
|---|---|---|
| A | 공시 데이터 재가공·시각화·알림 (조언 없음) | 규제 없음 ✅ v1 영역 |
| B | 불특정 다수 대상 유료 단방향 조언 (뉴스레터·방송형) | **유사투자자문업 신고** (금감원). 1:1 금지, 양방향 소통 금지 |
| C | 특정인 맞춤 자문 / 매매 실행 | 투자자문업/투자일임업 **등록** |

- 유사투자자문업 위반 리스크: 미신고 영업 1년 이하 징역, 1:1 자문·일임 시 3년 이하 징역/1억 벌금
- 출처: easylaw 위 링크 + 금감원 유사투자자문업 신고 안내 (명확하지 않은 출처 — 실행 전 금감원 원문 재확인)

**워딩 가이드 (A 레벨 유지 조건):**
- 금지: "추천", "매수 타이밍", "따라 사세요", "목표가"
- 허용: "OO 임원이 X주를 매도했다고 공시", "최근 30일 내부자 순매수 상위 종목" (사실 서술 + 집계)
- 경계: "주목할 만한", "이례적인" 같은 평가 워딩은 최소화. UI 카피 단계에서 법무 관점 리뷰 항목으로.

## 3. 정치인 재산공개 제도 (데이터 한계의 근거)

- 등록 대상: 소유자별 합계액 1천만원 이상 현금·예금·주식·채권 등 (공직자윤리법 §4)
- 주기: 전년도 재산변동사항을 **매년 2월 말일까지 신고** → 국회공보로 3월 말 공개 (2026년은 3/26 공개)
- 공개 단위: **잔액 스냅샷 (종목별 보유액)**. 거래 건별 내역·시점·가격 없음
- 가족: 배우자·직계존비속 포함, 단 "고지거부" 제도 존재
- 백지신탁: 3천만원 초과 직무관련 주식은 매각/신탁 원칙, 직무관련성 심사 예외 다수 (경실련 실태조사: 22대 의원 149명 증권 보유 2,575억, 매각·신탁 신고 6억 = 6.7% 수준)
- 출처: 인사혁신처 https://www.mpm.go.kr/mpm/info/infoEthics/BizEthics01/ · 경실련 https://ccej.or.kr/posts/rDtvGl6 · 정보공개센터 https://cfoi.or.kr/19170 (모두 2026-07 확인)

## 4. 입법 동향 (기회 모니터링)
- 이춘석 의원 차명거래 사건(2025.8) → 2026.3 금융실명법·공직자윤리법·청탁금지법 위반 혐의 검찰 재송치. 출처: 나무위키 정리 (1차 출처 언론 재확인 필요)
- 경실련 4대 개선 촉구: **주식 매매내역 신고제 도입**, 윤리위 심사 강화 등 (위 경실련 링크)
- **알림 설정**: 국회 의안정보시스템에서 '공직자윤리법 개정안' 키워드 주기 모니터링. 매매내역 신고제 통과 = 본 서비스 v2 확장 트리거.

## 5. 참고: 미국 원형의 법적 구조
- Autopilot은 정보회사(Autopilot Holdings)와 SEC 등록 투자자문사(Autopilot Advisers, LLC)를 분리해 자문·일임 기능을 라이선스 법인에 몰아넣는 구조 (출처: Autopilot 공식 고지문, 유저 제공)
- 한국에서 동일 구조 = 일임업 등록 법인 설립·제휴. 장기 옵션으로만.
